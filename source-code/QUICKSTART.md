# PsychTriage Quick Start Guide

## Getting Started

Welcome to PsychTriage! This guide will help you navigate through the application.

## Available Routes

### Main User Flow
1. **`/`** - Onboarding Screen
   - Welcome screen with animated introduction
   - Start your mental health check-in journey

2. **`/mood-checkin`** - Mood Check-In Screen
   - Select your current mood with emoji buttons
   - Adjust stress level with an interactive slider
   - View your daily streak and earn XP

3. **`/voice-input`** - Voice Input Screen (Optional)
   - Record voice input with waveform visualization
   - Real-time emotion detection
   - Transcript display

4. **`/ai-chat`** - AI Chat Screen
   - Conversational assessment with AI companion
   - Progress tracking
   - Earn completion badges

5. **`/risk-result`** - Risk Result Screen
   - View color-coded risk assessment
   - Get personalized suggestions
   - Access professional help resources

6. **`/dashboard`** - Progress Dashboard
   - View weekly mood trends
   - Track stress levels over time
   - See achievement badges
   - Check total XP and streaks

7. **`/emergency`** - Emergency Mode
   - Quick access to helplines (Tele-MANAS: 14416)
   - Safety tips and resources
   - Professional support contacts

### Design Resources
- **`/components`** - Component Library
  - Interactive showcase of all UI components
  - Button variants and states
  - Gamification elements
  - Risk cards and badges

- **`/design-system`** - Design System Documentation
  - Complete color palette
  - Typography scale
  - Spacing system
  - Icon guidelines
  - Border radius values

## Key Features

### Gamification
- **XP Points**: Earn experience points for check-ins and activities
- **Daily Streaks**: Maintain consecutive days of check-ins
- **Achievement Badges**: Unlock rewards for milestones
- **Progress Tracking**: Visualize your mental health journey

### Design Highlights
- **Mobile-First**: Optimized for smartphone screens
- **Calm Color Palette**: Teal, blue, purple, and warm yellows
- **Smooth Animations**: Motion-based micro-interactions
- **Emotionally Supportive**: Non-judgmental, encouraging UI

### Safety Features
- **Privacy Protected**: Confidential conversations
- **Emergency Support**: Quick access to helplines
- **Professional Resources**: Connect with mental health experts
- **Risk Assessment**: AI-powered mental health triage

## Color Codes

### Risk Levels
- 🟢 **Green** (#10B981) - Low Risk / Doing Well
- 🟡 **Yellow** (#F59E0B) - Moderate / Needs Support
- 🔴 **Red** (#EF4444) - High Risk / Immediate Help

### Primary Actions
- 🔵 **Teal** (#14B8A6) - Primary CTAs
- 🔵 **Blue** (#3B82F6) - Secondary actions
- 🟣 **Purple** (#A78BFA) - Special features
- 🟡 **Gold** (#FBBF24) - Rewards & XP

## Navigation

Use the floating navigation menu (top-right) to quickly jump between screens during development. This menu will be removed in production.

## Technical Notes

- Built with React 18.3.1
- Styled with Tailwind CSS v4
- Animated with Motion (Framer Motion)
- Routed with React Router 7
- Charts via Recharts
- Icons from Lucide React

## Indian Context

- Emergency numbers: Tele-MANAS (14416), KIRAN (1800-599-0019)
- Target audience: Indian youth and young adults (18-35)
- Culturally appropriate language and imagery
- Designed for Indian healthcare context

## Accessibility

- Keyboard navigation supported
- High contrast ratios
- Large tap targets (min 44x44px)
- Screen reader friendly
- Clear visual feedback

## Privacy & Security

- All conversations are confidential
- No data is stored without consent
- Secure and encrypted communication
- HIPAA-compliant design patterns
