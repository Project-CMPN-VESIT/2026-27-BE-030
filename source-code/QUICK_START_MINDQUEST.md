# 🎮 MindQuest - Quick Start Guide

## Access the Game

### Option 1: From Onboarding
1. Go to homepage (`/`)
2. Click **"Try MindQuest Game"** button

### Option 2: Direct Navigation
- Navigate to `/mindquest`

### Option 3: Navigation Menu
1. Click menu icon (top-right)
2. Select **"MindQuest Game"**

---

## Game Flow (5 minutes)

```
START
  ↓
🌟 Game Start → Level 1 → Level 2 → Level 3 → Results
                  Calm     Challenge   Stress    Actions
                  +50 XP   +75 XP      +25/Q
```

---

## Level Guide

### 🌬️ Level 1: Calm Mode
**Task:** Tap 5 floating objects while breathing
- Follow breathing circle (Inhale/Hold/Exhale)
- Tap: Cloud, Droplet, Leaf, Sun, Sparkles
- **Time:** ~2 minutes
- **Reward:** +50 XP

---

### 🧠 Level 2: Challenge Mode

#### Phase A - Quiz (3 questions)
- Answer mental health questions
- 30 seconds per question
- Immediate feedback (✓ or ✗)

#### Phase B - Memory (4 pairs)
- Match flower emoji pairs
- Flip cards to find matches
- **Time:** ~2 minutes
- **Reward:** +75 XP

---

### 🔥 Level 3: Stress Mode
**Task:** Answer 4 questions under pressure
- 15 seconds per question
- Random distractions appear
- Heart rate monitor visible
- **Time:** ~1 minute
- **Reward:** +25 XP per correct

---

## Results Interpretation

### 😊 Low Anxiety (Green)
- Score: 75%+ correct
- Meaning: Great stress management
- Action: View dashboard

### 😐 Moderate Anxiety (Yellow)
- Score: 50-74% correct
- Meaning: Could use support
- Action: View resources

### 😟 High Anxiety (Red)
- Score: <50% correct
- Meaning: Significant stress detected
- Action: **Talk to Support** (Tele-MANAS)

## Tips for Best Results

✅ **Be Honest**
- Answer based on real feelings
- Don't overthink responses

✅ **Stay Calm**
- Level 1 teaches breathing
- Use that technique in Levels 2-3

✅ **Ignore Distractions**
- Level 3 tests focus
- Stay on the questions

✅ **Take Time**
- No penalties for playing multiple times
- Use it as a self-check tool
